# Arch-Scripts

Personal utility scripts from `~/.local/bin` on Arch Linux.

- `appimgr`: AppImage manager
- `fbackup`: backup script
- `syscheck`: system health check
- `binvc`: GitHub Repo Help
- `ims`: Install My Scripts
- `shelf`: A deck for all my scripts
- `stage`: Niri window layout profiles (formerly `niri-ws`)
- `thermal-toast`: warns when the CPU stays too hot
